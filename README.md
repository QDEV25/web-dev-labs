# web-dev-labs
Complete collection of JavaScript laboratory work.  Topics include: syntax basics, Git workflow, functions, pure functions, recursion,  array methods (map/filter/reduce), currying, prototypes, constructors,  inheritance, and web server development.
## Labs Included:
- Lab 1: JavaScript syntax, loops, arrays, functions
- Lab 2: Grade analysis program with Git workflow
- Lab 3: Function declarations, expressions, arrow functions, closures
- Lab 4: Pure functions, recursion, map/filter/reduce, currying
- Lab 5: Objects, prototypes, constructors, inheritance
- Web Server Lab: HTTP server with routing and JSON data

## Technologies:
- JavaScript (ES6+)
- Node.js
- Git
- HTML/CSS
